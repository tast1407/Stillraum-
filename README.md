Stillraum ist ein Projekt für eine ruhige, datenschutzorientierte Suche im Internet.

Ziele

* Eine einfache, übersichtliche Suchoberfläche
* Möglichst wenig Datensammlung
* Ein privater Bereich für persönliche Notizen
* Verschlüsselung sensibler Inhalte
* Später Unterstützung für Smartphones und Computer

Aktueller Stand

Der vorhandene Prototyp ist eine statische HTML-Demo. Die Suchergebnisse sind Beispieldaten. Eine echte Websuche, Benutzerkonten und ein sicherer Online-Speicher sind noch nicht eingerichtet.

Datenschutz

Der Prototyp speichert verschlüsselte Notizen lokal im Browser. Das ist noch kein vollständiges Sicherheitskonzept für einen öffentlichen Dienst. Vor einer Veröffentlichung müssen insbesondere Authentifizierung, Schlüsselverwaltung, Datenlöschung und Sicherheitsprüfungen geplant werden.

Entwicklungsplan

1. Weboberfläche verbessern
2. Echte Suchanbieter datenschutzbewusst integrieren
3. Sicherheitskonzept prüfen
4. Responsive Website veröffentlichen
5. Smartphone-App entwickeln
